# The Aura House — corporate landing page

Static site published with GitHub Pages: **The Room They Turn Up For**,
the corporate wellness & engagement landing page for The Aura House.

- `index.html` — the page (self-contained markup, external media)
- `media/` — photos, posters and video files
- `fonts/` — self-hosted Playfair Display and Montserrat
- `privacy.html`, `terms.html`, `cookies.html`, `refunds.html` — policies
- `testimonials.html` — the full testimonial wall

Built from `site/build.py` in the private `shahpoojaaura/cmo` repo.
Each deploy replaces the whole tree in a single commit, so the
repository never accumulates old copies of the media.
